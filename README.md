# okinawa_geography_puzzle
## 遊び方

1. 「名前表示」または「特徴ヒント」を選び、「ゲーム開始」を押します。
2. 未配置ピースをドラッグし、十字の照準を正しい自治体の陸地内に合わせて離します。正解すると形が固定され、誤りの場合は元の置き場に戻ります。
3. ドラッグの代わりに「ピースをクリック／タップ → 地図上の陸地をクリック／タップ」でも置けます。
4. 全41市町村を置くと完成。時間と配置数を表示します。

## 表示と操作

- 本島＋離島／本島のみ／離島のみを切り替えられます。配置状況と時間は維持されます。表示切替は地図の見え方だけで、完成条件は全41ピースです。
- 本島の自治体に属する付属島は本島表示に含めます。伊江村・伊平屋村・伊是名村など、島の自治体は離島表示です。
- 地図の背景をドラッグして移動。＋／−、ホイール、2本指のピンチで70〜1800%に拡大・縮小。「全体に戻す」で初期表示。
- 「地域を拡大…」で本島南部、宮古諸島などに直接移動できます。小さな自治体は拡大して配置してください。
- 画面幅を変えると地図を再配置し、ズームをリセットします。ゲームの配置・経過時間は保持します。
- ⛶ボタンで地図の高さを広げます。
- トレイの形をつかむとドラッグ、余白やスクロールバーを操作すると一覧をスクロールします。スマートフォンでドラッグ中に画面の上下端へ寄せると、ページが自動でスクロールします。
- ヒント欄を押すと、産物・歴史・文化などの詳細を開閉できます。出典リンク以外はオフラインで利用できます。
- スマートフォンでは選択中の簡易ヒントを画面下に表示します。「詳しく」で詳細パネルを開けます。
- 「完成図を見る」では配置数は変わりません。ゲーム中の時間は進み続けます。
- モードは開始前に選択します。変更する場合は「やり直す」でモード選択に戻ります。
- リロード・ブラウザー終了時に進行状況は保存しません。

## キーボード

Tabでピースに移動し、Enter／Spaceで選択。地図にフォーカスが移ります。
矢印で照準を12px、Shift＋矢印で2pxずつ移動、Enterで配置、Escで選択解除。
ピースを選んでいない場合、矢印で地図を移動します。＋／−で拡大縮小、Homeで全体表示。

## 地図・ピース設計

41市町村を1自治体1ピースで扱い、自治体の統合は行っていません。小さな自治体も拡大表示とタップで操作します。複数の島・飛び地を持つ自治体は、自治体IDで連動し、別枠の島も一度に配置します。回転操作はなく、北が上です。

配置済み地図の小さな自治体には番号を表示し、地図下の名称一覧で完全な名称を確認できます。特徴ヒントモードでは完成時に全自治体の名称／番号が表示されます。

地図は2021年1月1日時点の国土数値情報を使用しています。現在の埋立地等をすべて反映した地図ではありません。所属未定地は灰色で参考表示し、ピースには含めません。詳しくは `DATA_SOURCES.md` と `ADJACENCY.md` を参照してください。

## ファイル構成

- `index.html`：画面とダイアログ
- `style.css`：PC・スマートフォン用の表示
- `app.js`：ゲーム状態、描画、入力、判定
- `data.js`：地域投影済みの地図、自治体ID、ヒント、出典
- `DATA_SOURCES.md` / `HINT_SOURCES.md`：出典と加工内容
- `ADJACENCY.md` / `GEOMETRY_CHECK.json`：隣接・海岸線確認と処理記録

## 対応ブラウザー・検証範囲

Pointer Events、SVG、dialog、ResizeObserverに対応した現行のEdge・Chrome・Firefox・Safari向けです。実際の動作検証はWindows版Edgeと、Edgeのスマートフォン・タッチエミュレーションで行っています。iPhone／Androidの実機、Firefox／Safari実機は未検証です。
